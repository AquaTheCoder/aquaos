# AquaOS

AquaOS is an imitation of Windows on the web. It is still in its early stages.

## Features

- Saves notes locally
- Draggable windows
- Themes
- Terminal with some commands
- About app
- Local time

## Themes

3 themes:

- Image 1
- Image 2
- Monochrome color

## Languages

- HTML
- CSS
- JavaScript
